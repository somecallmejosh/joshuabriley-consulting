“Hey Logatot” — listening for wake word
  1. Four live counts, each derived from the child's schedule against today's events rather than stored anywhere. Tapping one opens the detail panel below it, and only one is ever open — a provider glancing at this screen is answering one question, not comparing four.
  2. The panel loads its roster as a fragment on click rather than up front, so the grid paints immediately on a tablet running on domestic WiFi.
  3. Diaper-change and health-check alerts are computed from per-account intervals against each child's last logged event. They render empty and fill after load, so a slow reminder query never delays the grid behind it.
  4. Every event column can be hidden, and the choice persists per device — meals and “learned today” start hidden. The show-all control only appears once something is hidden, so the toolbar stays quiet for the provider who never changed anything.
  5. One row per child, one column per event type, one day. Rows scroll horizontally in sync, so a provider scanning right stays on the same time axis across all twelve children — without that, the grid is twelve unrelated timelines that happen to be stacked.
  6. The wake word is detected on-device: no audio leaves the browser to trigger it. Speech is transcribed, parsed into a structured event, and the affected row updates in place over a live socket — nothing to refresh, and her hands stay where they are.
