Something look wrong on an application? Message your recruiter.

Update availability
  1. This is the only screen a non-employee sees, and it carries the agency's name rather than VMSpark's. Everything internal comes off with it: no VMS source, no requisition ID, no processing state. A candidate has no use for the fact that a listing arrived from Medefis, and telling her would leak which agencies share which facilities.
  2. The count is honest about what it excludes and silent about why. A listing reaches this page only once its profession and specialty resolve to mapped values, so an unmapped profession is not an error a candidate ever sees — it is an assignment that was never advertised. That is the clearest way mapping debt turns into a lost placement, and it is invisible from this side of the product.
  3. Pay rate leads at the largest size on the card, then city, shift and start date. Those are the four fields the operator grid pushes out to columns seven through ten, because an operator triages on identity and state while a clinician decides on money and logistics. Same records, opposite priority, so the layout is rebuilt rather than reskinned.
  4. Candidates browse on a phone between shifts, so the one write on the surface gets a 44px full-bleed target and a plain estimate of what it costs them. There is no account wall in front of it — the account is created from the application. Once applied, the button is replaced in place by the dated state, because the card is where she will look first.
  5. "Did that go through" is the commonest thing a candidate rings her recruiter about, and every one of those calls is a support cost created by a portal that cannot answer it. The stepper is dated at each step, and the labels describe where the application physically is, not what the pipeline calls that stage.
  6. This surface is public, so accessibility is an acceptance criterion rather than a later pass: full keyboard operability, a visible focus ring that survives the token layer, focus moved deliberately after an apply, and contrast checked at the token level so no future theme can quietly fail it.
