# Wireframes & User Flows — IVFCRYO

Annotated lo-fi wireframes and user-flow diagrams reconstructed from the shipped
application, for use as design assets in the portfolio case study.

Each frame carries a numbered annotation layer in the right margin explaining the
design reasoning behind the screen — not a description of what is on it.

## Notes

Images are rendered at 2× (3200px wide) for print and retina display. They are
reconstructions of the delivered product, drawn after the fact to document the
design reasoning — not the original working files.
