## Selected work

Eyebrow:
Selected work

Heading:
Products I owned end to end

**Clempo**
A multi-tenant personal-finance app with real households using it. I own the whole stack: authentication, tenancy, data modeling, and the interface. Built to keep more than one household's data correct and private at once.

**IVFCRYO**
Accessible specimen-shipping flows for a fertility logistics product. Recoverable forms and a rebuilt shipping path cut support calls by [75%] and shipping errors by [55%]. Accessibility was the mechanism that moved the numbers, not a checkbox.

**VMSpark**
A multi-tenant Rails admin platform, rebuilt and shipped in four phases with no feature flags and zero pipeline regressions. I inventoried 350 templates, consolidated them onto one component system, and routed the UI back through a single token layer, with no operator retraining.

**West Baton Rouge Presbyterian**
A custom Rails CMS built end to end over one weekend: content models for events, galleries, and pages, a Cloudinary media pipeline, staff authentication, and an accessible public site. Proof of range and speed.

**Bass Face**
A practice tool I built for myself in React, with Tone.js for generative backing tracks and a Claude API integration for reflective feedback. Shows creative range and comfort wiring up live services into a real product.

**America's Test Kitchen**
When a product needs a real design system, I build that too. One React and Next.js component library serving three editorial brands with zero brand-fork props, and one accessibility floor every team inherits.

(Smaller, below the main grid:)

**drift and Pattern Sense**
I care about quality enough to build the tooling that enforces it: a design-system drift auditor that measures UI debt in counts and hours, and a decision guide for choosing accessible interface patterns.
