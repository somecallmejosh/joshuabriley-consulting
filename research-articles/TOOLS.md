Users select or upload a simple component example (or choose from presets like Button, Card, Form field). The tool shows common real-world drifts (inconsistent spacing, variant explosion, missing states, color mismatches) alongside a "structured" version using proper tokens and patterns. Why it fits: Directly illustrates "I fix inconsistent UI systems."
Value: Instant "aha" moment + clear before/after that mirrors your audit findings demo.

Why it fits: Reinforces your governance and structure expertise.
Value: More personalized than the current one; users feel seen.

Accessibility Pattern Auditor Lite
Users select a common pattern (modal, data table, navigation, form) and adjust props/states. The tool flags WCAG issues (contrast, ARIA, keyboard, focus management) with explanations and "good" vs "bad" live examples. Include a simple keyboard navigation simulator.
